## Local development setup

Learn how to build a local development setup for Zitadel with Docker Compose without breaking your quickstart with race conditions. This hands-on tutorial covers extending your Docker Compose file to run Zitadel alongside Postgres, handling service dependencies, configuring health checks, and avoiding common pitfalls. Includes master key setup, TLS configuration for development, and getting the Zitadel console running on localhost:8080. Follow along with the actual Zitadel documentation examples and learn why order matters in your compose files. Perfect for developers who want a working Zitadel setup fast without the headaches.
