You probably enter a lot of different commands into your terminal every day, right? Those commands could be useful in every directory ... sure; but more often than not, they're specific to the directory you're in.

So why do you use a global command history? That changes today:

https://github.com/jimhester/per-directory-history


If you find that you need to search your global history, you can switch back and forward with <kbd>Ctrl + g</kbd>
Enjoy
