---
title: "Understanding MCP"
description: A walk through the Model Context Protocol, one piece at a time.
---

The Model Context Protocol (MCP) is how AI applications such as Claude Code,
ChatGPT and Visual Studio Code reach your files, databases and tools. In this
series I take it apart one piece at a time, following spec version
2026-07-28. Start with the first part: it follows a single question from your
prompt to an MCP server and back.
