# Rawkode Academy Flutter app

Native Flutter work in progress for Android, iOS, and desktop. Kubele, CNIcon, account sign-in, the course catalog, and video playback have initial implementations. The Android workflow generates platform files and uploads a debug APK after analysis and tests. Production readiness requires end-to-end validation, additional approved features, platform setup and testing, and rollout of the matching identity and website API changes.

Courses and videos load directly from the existing public Academy GraphQL API. The mobile OAuth client and game API routes in the identity and website projects must be deployed before the app can sign in or load canonical game data. Apply the identity database migration as part of the normal deployment. Until those changes are deployed, an APK built from this branch cannot complete account and game flows against production services.

For local development, install Flutter and run `flutter create --platforms=android,ios,linux,macos,windows .`, `python3 tool/configure_android.py`, `python3 tool/configure_apple.py`, `flutter pub get`, `flutter test`, and `flutter run`. Platform builds require their respective SDKs and supported host operating systems. The scripts configure Android, iOS, and macOS callbacks; those Apple platforms still need device builds and verification. Windows and Linux need a supported native OAuth implementation before sign-in can work.
